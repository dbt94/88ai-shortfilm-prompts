Why assembled this way? Three counter-intuitive rules run through every output: ① name real camera/lens models instead of the vague word "cinematic"; ② actively describe imperfections (wear, stains, fatigue) — perfection reads as fake; ③ leave the ending empty — no score piling on emotion, no explosion-style close. Full methodology: methodology.md.
